# Soroban Contracts

Polaris on-chain smart contracts for vaults and permissions.

## Project Structure

```text
contracts/
├── contracts/
│   └── vault/          # Core vault contract (placeholder)
├── Cargo.toml          # Workspace manifest
└── README.md
```

## Build

```bash
cd contracts/vault
make build
```

## Test

```bash
cd contracts/vault
make test
```
